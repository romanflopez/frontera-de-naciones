# Cliente

Cliente de Frontera de Naciones: Phaser 3 para el mundo y React para la interfaz. Viene de `mp-client` de
[helbreath-base-game](https://github.com/ErkoKnoll/helbreath-base-game) (MIT).

Se corre desde la raíz del repo con `pnpm dev`. Ver el README principal.

- `src/game/`: escenas, objetos (jugador, mobs, NPCs) y lectores de los formatos `.spr` y `.amd`.
- `src/ui/`: diálogos y overlays en React.
- `src/constants/`: catálogos de mobs, items, efectos y el manifiesto de assets.
- `public/assets/`: assets provisorios generados con `pnpm assets` (no se suben al repo).
